# BabyNews MCP extension for Gemini CLI

Connects Gemini CLI to the BabyNews (베이비뉴스) MCP server: Korean pregnancy, birth and parenting articles, curated Q&A and regional childbirth support programs. Read-only, no account needed.

```
gemini extensions install https://github.com/lifenplanner/babynews-gemini-extension
```

Server: https://www.ibabynews.com/mcp (Streamable HTTP) · Guide: https://www.ibabynews.com/mcp-guide · Contact: pr@ibabynews.com
